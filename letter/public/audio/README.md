# Audio de fondo

Coloca aquí el archivo `background.mp3` (ruta `/audio/background.mp3`).

- Fragmento de 2–5 minutos que haga bucle limpio (recortado del video original).
- MP3 (o M4A/AAC cambiando `BACKGROUND_AUDIO_SRC` en `src/lib/audio.ts`), 128–160 kbps.
- Sin este archivo la app funciona, pero no suena nada.
